Scope

osm-d covers OSM semantic data, PBF/XML/osmChange codecs, editable stores, topology and complete-object resolution, area assembly, Editing API protocol semantics, authoritative synchronization and replication. Generic transport, credentials, geometry, spatial indexing, rendering and application workflow remain separate concerns.
